把你的第一卷，写进无限图书馆

恭喜通过入学礼。人类建过一座最大的图书馆，收藏着世上几乎所有公开的代码——它的麻瓜名字叫 GitHub，我们叫它无限图书馆。每个巫师都能在里面拥有一格自己的书匣。 今天你要做三件事：办借书证、开书匣、封印第一卷。全程只需要浏览器和一个邮箱，约十五分钟。

免费 · 纯浏览器 · 零安装 · 完成即得魔力值 +150

01

办借书证

未解锁

进入无限图书馆需要一张借书证——就是一个免费的 GitHub 账号。

✦猫头鹰已飞到注册页…填好邮箱、收验证邮件、设好密码后，回来点下面的按钮收回执。

放出猫头鹰 · 去办证
02

开一格书匣

未解锁

书匣（麻瓜叫 repository / 仓库）是图书馆里属于你的一格，以后你的作品都放在里面。

  • 登录后打开 github.com/new
  • 仓库名填 my-first-spell（也可以是你喜欢的名字）
  • 选 Public —— 公开的书匣朋友才看得到
  • 务必勾选 Add a README file —— 这会顺便放进一卷空白卷轴
  • 点绿色按钮 Create repository

✦猫头鹰守在新建页面旁…建好书匣、看到仓库页面后再回来。

放出猫头鹰 · 去开匣
03

封印第一卷

未解锁

现在往空白卷轴里写点东西，然后盖上你的第一个封印——麻瓜叫它 commit。这是每个工程师每天都要施的咒。

  • 在你刚建的仓库页面，找到 README.md 文件名右侧的铅笔图标，点它进入编辑
  • 把内容改成你自己的一句话，比如：# 我的第一道咒语
  • 点右上角绿色按钮 Commit changes，弹窗里再点一次 Commit changes
git commit -m "我的第一道封印"
示意演示 · 你在网页上点按钮时，GitHub 正替你执行这句咒

✦猫头鹰陪你进了编辑页…改好 README、点完绿色 Commit 后回来。

放出猫头鹰 · 去封印
