在石碑上，铭刻你的第一道咒

前两关你学会了封印卷轴（commit）和让历史生长。但你把它们用过的地方，还是那样一块空白石碑。 现在轮到你做一件许多新手一直不敢做、也一直不会做的事：给一个已有的真实作品，施一道咒语，改一处真实的地方。 不需要从零开始。你只需要说一句准确的咒语，使魔（AI）会帮你把它刻进石碑。

免费 · 纯浏览器 · 约十五分钟 · 完成即得魔力值 +210 并与「施咒学徒」称号

01

打磨碑面

未解锁

你的石碑就是你的 GitHub 仓库。第一步先把它打磨干净——看清楚碑面上现在刻着什么。

  • 打开你的书匣（上一关的仓库链接）
  • 点开 README.md 看看里面现在有几行字
  • 心里想好一个你最想补上的一句：一个自我介绍、一句说明、或一个想加的角落

✦猫头鹰守在仓库页旁…想好你要刻什么后回来。

放猫头鹰去仓库
02

磨墨：准备你的咒语

未解锁

铭刻新符文前，先磨好墨。对零基础者，最好的咒语不是一句糊涂的「帮我改」，而是一句讲清楚要什么、给足上下文的话。

把下面这句话复制进你的 AI 工具（网页版即可）： 「我的仓库叫 [你的仓库名]，主要是一个学习 vibe coding 的练习仓库。请帮我在 README 里加一句真诚的介绍，告诉看我仓库的人——我正在学用 AI 做小作品，这是我的第一个练习项目。」

把 [你的仓库名] 换成真的，然后照抄。你可以在网上搜索「Claude」「ChatGPT」「DeepSeek」等任一 AI 网页工具的地址。

✦猫头鹰把咒语叼去 AI 工具了…拿到它给你的文本后回来。

带上咒语出发
03

落墨：把咒语刻进石碑

未解锁

拿到 AI 给你的文本后，把它刻进你的仓库，然后封印。

  • 回到仓库页，点 README.md 的铅笔图标编辑
  • 把 AI 给你的那句介绍，粘贴进 README（可以保留原来的话）
  • 点 Commit changes 两次确认——这就是你的第一道真实刻痕
git commit -m "铭刻第一道咒：给石碑加了一句自我介绍"
[main e1a2b1] 铭刻第一道咒：给石碑加了一句自我介绍
示意演示 · 你在网页上点按钮时，GitHub 正替你执行这句咒

✦猫头鹰陪你在编辑页…改好、点完 Commit 后回来。

落墨封印
04

再刻两痕

未解锁

一道刻痕只是一粒符文。要点亮三门，我们需要同样的咒语仪式再施两次——每次改一处真实的地方。

  • 第二道刻痕：再写一句咒语给 AI，请它给 README 加一个「我学到了什么」的小节，或列上你正在学的东西
  • 第三道刻痕：再写一句，请它帮你在仓库里「加一个简单的说明文件」或「整理 README 的排版」，然后照例 commit 两次
  • 三道刻痕都落墨后，你的石碑就有三粒符文亮起，第一章就此收官
git commit -m "铭刻第二道咒：罗列我正在学的东西"
git commit -m "铭刻第三道咒：整理石碑排版"
示意演示 · 每道刻痕都是一次真实 commit

✦猫头鹰陪你完成后两道刻痕…三处都改好、都 commit 后回来。

继续落墨

封印凭证
