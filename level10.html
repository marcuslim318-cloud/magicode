倒转时光沙漏，改坏了也不怕

上一关你不再怕报错。今天要再学会一张护身符：改坏了也能回到好状态。 你的每一件作品都会在历史里留下印记——时间转换器就是教你看准、倒回去。 用 git 的〈revert〉，让**搞坏的改动**像沙漏一样倒转，凭什么你都会、都敢试。

免费 · 纯浏览器 · 约二十分钟 · 完成即得魔力值 +420

01

第一转：故意做一个「会后悔的改动」

未解锁

别怕，先知道自己在练功。在你的作品里做一个会坏掉、打算撤销的小改动——比如删掉一句话、改错一个颜色、弄坏一个链接——然后照常 commit 上去。这一步是为了让坏改动成为历史的一格。

把下面这句粘贴给你的 AI（或直接手动改）： 「故意帮我在 index.html 里弄坏一个小地方（比如把标题改成乱码、把背景色改得很刺眼），然后告诉我应该 Commit 成一条消息，比如：'测试：这次我会后悔的改动'。」

改完 Commit，记下这一格的样子——待会儿要把它倒回去。

✦猫头鹰帮你把坏改动 Commit 上去…沙漏开始漏空后回来。

放猫头鹰去犯个故意的小错
git commit -m "测试：这次我会后悔的改动"
示意演示 · 你在 GitHub 网页上操作时，正在执行同样的动作
02

第二转：看清历史，找到好时光那一格

未解锁

坏文件已经 Commit 上去了，别慌。现在看看历史记录，找到「上一次还好好的」那一格——通常是坏改动的前一条。每一行历史都是你能回去的时间。

  • 打开仓库的 Commits / 历史 标签页
  • 找到坏动态【测试：这次我会后悔的改动】
  • 记住它下面那条对应的提交标识（一串字母数字）——那是好时光

✦猫头鹰陪你翻历史…找到好时光那一格后回来。

放猫头鹰去翻历史
03

第三转：倒转沙漏，revert 回去

未解锁

最后一步：GitHub 网页上，点坏动态那条旁边的 Revert 按钮，确认创建一个「反向」的提交——它不删历史，只把坏改动补回来。这个逆向提交就叫 rever，时光倒转，作品回到好状态。

git revert <好时光的提交标识>
作品恢复了 · 沙漏已倒转
示意演示 · GitHub 网页上的 Revert 按钮做的事，就是这条命令

revert 后刷新你的线上作品——页面又好了，而历史里多了一条诚实的「撤销记录」。你拥有了无惧改坏的能力。

✦猫头鹰陪你倒转沙漏…作品恢复如初后回来。

放猫头鹰去 revert
