披上星光长袍，让作品好看

前几关你的作品会动、会读世界——但它的样子可能还朴朴素素。今天要给它披一件星光长袍： 用咒语换掉作品的皮肤。配色、字体、布局，一层层披上去，它就从朴素小袄变成华丽华服—— 外表，同样是你的创作。

免费 · 纯浏览器 · 约二十分钟 · 完成即得魔力值 +330

01

第一层：换一套配色皮肤

未解锁

第一层长袍：让作品换一套好看的颜色。背景、文字、标题配色一变，页面的气质立刻不同。这是皮肤最立竿见影的一部分。

把下面这句粘贴给你的 AI 工具： 「请把之前的 index.html 换一套更好看的配色主题：你挑一组和谐的颜色做主背景、正文和标题（例如深夜蓝配暖金，或淡绿配深棕）。保留所有功能和布局，把更新后的完整 index.html 全文给我。」

替换、Commit、刷新——页面颜色应整个变了一套。

✦猫头鹰叼来第一层长袍…配色换上、确认好看后回来。

放猫头鹰去披配色
git commit -m "第一层长袍：作品换上了更好看的配色"

02

第二层：换一套字体与排版

未解锁

第二层长袍：让文字更好读、更好看——换字体、加大标题、调段落间距。排版是皮肤的骨相，决定了页面给人的精细感。

把下面这句粘贴给同一个 AI： 「请再给 index.html 升级字体和排版：标题用更醒目的字体、大一点，正文行距放宽更易读，给标题加点间距。保留所有功能和配色，把更新后的完整 index.html 全文给我。」

替换、Commit、刷新——文字整体变精致了。

✦猫头鹰带回第二层长袍…排版更精后回来。

放猫头鹰去换排版
03

第三层：加布局与装饰点缀

未解锁

第三层长袍：给作品加一点布局和装饰——卡片式排版、圆角、阴影、分隔线或小图标。这是让页面从「能看」到「耐看」的最后一道。

把下面这句粘贴给同样的 AI： 「请最后给 index.html 加布局和装饰：把主要内容做成好看的卡片样式（圆角+柔和阴影），加一条装饰分隔线。保留所有功能，把更新后的完整 index.html 全文给我。」

替换、Commit、刷新——长袍三层披齐，作品华丽变身。

✦猫头鹰带回缀满星光的第三层…三层都披好了后回来。

放猫头鹰去缀装饰
