去第 1 关 · 封印人生第一卷

让卷轴在时间里生长

上一关你封印了人生第一卷。现在沙漏开始转动——每做一次新的封印（commit），沙漏下层就多落一粒金沙。封印三次，金沙堆积成历史；然后你将学会一件所有巫师都必须掌握的禁术：时间转换器——把沙漏倒转，让一粒金沙飞回上层，改写刚刚发生的事。

免费 · 纯浏览器 · 约十五分钟 · 完成即得魔力值 +180

01

封印第二卷

未解锁

打开你上一关建的书匣，往里再写一行字，然后封印它。

  • 打开你的书匣页面（上一关贴过的链接）
  • 找到 README.md，点铅笔图标编辑
  • 在原有内容下方加一行，比如：第二道封印：我正在学版本控制
  • 点 Commit changes（绿色按钮）两次确认

✦猫头鹰在编辑页旁守着…改好、点完 Commit 后回来。

放出猫头鹰 · 去封印
git commit -m "第二道封印：我正在学版本控制"
[main a1b2c3] 第二道封印：我正在学版本控制
示意演示 · 沙漏下层落下了第一粒金沙
02

封印第三卷

未解锁

再来一次。这一次你已经开始感觉到——每一次封印都在时间里留下痕迹。

  • 再次编辑 README.md，加一行你喜欢的话
  • 点 Commit changes 两次确认

✦猫头鹰又出发了…封好后回来。

放出猫头鹰 · 去封印
git commit -m "第三道封印：一切皆可追溯"
[main d4e5f6] 第三道封印：一切皆可追溯
示意演示 · 沙漏下层又多了一粒金沙
03

看见历史

未解锁

三道封印落下后，沙漏下层已经有三粒金沙。现在去 GitHub 看看你的提交历史——那里记录着你做过的每一件事。

  • 在你的书匣页面，点上方的 commits（或提交记录）链接
  • 你会看到三行提交记录，最新的一条在最上面
  • 每一行就是一粒金沙——它们按时间排列，组成你的卷轴生长史

✦猫头鹰引你到提交记录页…数一数，三粒金沙都躺在那里。

放出猫头鹰 · 去看历史
git log --oneline
d4e5f6 第三道封印：一切皆可追溯
a1b2c3 第二道封印：我正在学版本控制
0898a98 我的第一道封印
示意演示 · 三粒金沙按时间从新到旧排列
04

时间转换器

未解锁

现在是最酷的部分：你刚刚封印的第三卷，其实可以"撤销"——在魔法世界里，这叫时间转换器（麻瓜叫 git revert）。它不会真正抹掉历史，而是多落一粒金沙，上面刻着"此处已修正"。

  • 回到你的书匣页面，点上方的 commits
  • 找到你要撤销的那条提交（比如最新的第三道封印），点它右边的 ··· 按钮
  • 选择 Revert commit，然后在弹窗里点 Revert commit 确认
  • 回到 commits 页面：你会看到最上面多了一条新的——这就是时间转换器落下的"修正金沙"

关键理解：旧的金沙没有消失，只是被新的一粒"否定"了。这就是版本控制的魔法——时间是可追溯、可修正的，但永远不可抹除。

✦沙漏正在倒转…操作完成后回来。

启动时间转换器
git revert HEAD --no-edit
[main b7c8d9] Revert "第三道封印：一切皆可追溯"
示意演示 · 沙漏倒转，一粒修正金沙落下
